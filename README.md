# BlinkIT Sales Analysis 📊
## Project Overview
This project analyzes BlinkIT grocery sales data using Power BI and Excel.
The objective is to understand sales performance, product categories,
outlet characteristics, and other important business KPIs.

## Tools Used
- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- DAX

## Key Analysis
- Total Sales
- Average Sales
- Number of Items
- Average Rating
- Sales by Item Type
- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Outlet Type
- Fat Content Analysis

## Files
- `BlinkIT Grocery Data.xlsx` – Dataset used for analysis
- `blinkit sales.pbix` – Power BI dashboard
- `Blinkit Analysis.pptx` – Project presentation
